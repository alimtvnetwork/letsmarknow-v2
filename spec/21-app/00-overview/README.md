# 00 — Overview

This folder is the entry point for any human or AI reading the spec. It explains **what** Lets Mark Now is, **why** it exists, **who** it is for, and **how** it compares to its inspirations (Toby and Tab Extend).

## Files in this folder

| File | Purpose |
|---|---|
| `vision.md` | The product vision, mission, north-star metric, and non-goals. |
| `glossary.md` | Canonical names for every concept (Workspace, Space, Collection, Group, Item, Share, etc.). All other spec files MUST use these terms. |
| `personas.md` | The three primary user personas with goals, frustrations, and key flows. |
| `competitive-analysis.md` | Side-by-side analysis of Toby vs Tab Extend vs Lets Mark Now. Lists every flaw we are fixing. |

## Reading order

1. `vision.md` — understand the why.
2. `glossary.md` — lock the vocabulary.
3. `personas.md` — understand who you are building for.
4. `competitive-analysis.md` — understand what is already on the market and where we win.

> ⚠️ **Naming is locked in `glossary.md`.** Any deviation in code, UI copy, API, or other spec files is a bug.
