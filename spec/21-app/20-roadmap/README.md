## Locked rules

- **Each phase is a 4-12 week increment** (no monolithic launches).
- **No phase ships without monitoring + rollback plan.**
- **Phases are sequenced by dependency**, not desire.
- **Cut scope, not quality** — locked rules from earlier sections never relax.
- **Public roadmap** lives at `letsmarknow.com/roadmap` (high-level only; this doc is internal).
- **Priorities can shift** based on user research and analytics signals; this doc reflects current intent.
