## Conventions used

- Diagrams are written in Mermaid (`flowchart` or `sequenceDiagram`) so they render directly inside Markdown previews and on GitHub.
- Every diagram is paired with a one-paragraph plain-language walkthrough beneath it.
- Diagrams describe the **user's experience**, not the database schema (that lives in `02-data-model/`).
- File `13` is intentionally absent — that number is reserved/skipped in the folder sequence.
